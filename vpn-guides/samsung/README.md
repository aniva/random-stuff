## Этап 1: Регистрация через Telegram-бота

1. Откройте Telegram и найдите бота: **`@aniva_vpn_bot`**.
2. Нажмите **Start** (или отправьте команду `/start`).
3. Бот попросит ввести:
   * **Ваше имя** (например, `Alexey Ivanov`).
   * **Ваш Email** (для отправки кода подтверждения).
4. На указанный email придёт 6-значный код. Отправьте этот код боту.
5. Бот подтвердит почту и отправит запрос администратору на подтверждение доступа.

Для работы с протоколом VLESS Reality на Android используется лучший открытый клиент — **v2rayNG**.

1. Перейдите на официальную страницу релизов:

## Этап 3: Установка приложения и обход Samsung Auto Blocker

На смартфонах Samsung One UI включена функция **Auto Blocker (Автоблокировка)**, которая по умолчанию запрещает установку файлов не из Galaxy Store / Google Play.

1. Откройте стандартное приложение **Мои файлы (My Files)** $\rightarrow$ папку **Загрузки (Downloads)**.
2. Нажмите на скачанный файл `v2rayNG_..._arm64-v8a.apk`.
3. Если появится предупреждение *"Установка неизвестных приложений"* $\rightarrow$ нажмите **Настройки (Settings)** и включите переключатель разрешения для приложения *Мои файлы*.
4. Если Samsung покажет предупреждение **Auto Blocker (Автоблокировка)**:
   * Перейдите в **Настройки телефона $\rightarrow$ Безопасность и конфиденциальность $\rightarrow$ Автоблокировка (Auto Blocker)**.
   * Временно отключите (Toggle Off) или отключите опцию *"Блокировать приложения из неавторизованных источников"*.
5. Нажмите **Установить (Install)**.
6. После установки нажмите **Открыть (Open)**.

## Этап 4: Импорт настроек подключения из буфера

1. Вернитесь в **Telegram** в диалог с ботом **`@aniva_vpn_bot`**.
2. После одобрения администратором бот пришлет сообщение со статусом `Approved ✅`, персональной ссылкой `vless://...` и QR-кодом.
3. **Скопируйте** текст ссылки `vless://...` в буфер обмена телефона (долгое нажатие $\rightarrow$ Скопировать).
4. Откройте приложение **v2rayNG**.
5. Нажмите на значок **`+`** в правом верхнем углу.
6. Выберите пункт **Импорт конфигурации из буфера обмена (Import config from Clipboard)**.
7. Профиль сервера моментально появится в списке.

## Этап 5: Подключение, разрешения и проверка связи

1. Нажмите на добавленный сервер в списке (слева появится зеленая вертикальная полоска активности).
2. Нажмите на круглую кнопку **V** в правом нижнем углу экрана для запуска.
3. При запросе:
   * **Устройства поблизости (Nearby devices)** $\rightarrow$ выберите **Не разрешать (Don't allow)** *(это не требуется для VPN)*.
   * **Запрос на подключение (Замочек / Ключ VPN)** $\rightarrow$ нажмите **ОК / Разрешить (OK / Allow)**.
4. Нажмите на нижнюю плашку **"Подключено, нажмите для проверки связи"**:
   * Появится реальный пинг (задержка в миллисекундах, например `180 ms`).
5. Откройте любой браузер и проверьте свой внешний IP (например, на сайте [ipinfo.io](https://ipinfo.io)).

## Частые проблемы и тонкая настройка Samsung

### 1. Отключение оптимизации аккумулятора (чтобы Samsung не выключал VPN в фоне)
1. Откройте **Настройки $\rightarrow$ Приложения $\rightarrow$ v2rayNG**.
2. Выберите **Батарея (Battery)**.
3. Установите режим **Не ограничено (Unrestricted)**.

### 2. Конфликт персонального DNS (Private DNS) на Samsung
Если в браузере не открываются сайты или появляется ошибка DNS:
1. Откройте **Настройки $\rightarrow$ Подключения $\rightarrow$ Другие настройки $\rightarrow$ Персональный DNS-сервер**.
2. Переключите его в положение **Выключено (Off)** или **Автоматически (Automatic)**.

### 3. Режим раздельного туннелирования (Split Tunneling)
Если необходимо пускать через VPN только отдельные приложения (например, заблокированные сервисы):
* В **v2rayNG** откройте боковое меню $\rightarrow$ **Настройки** $\rightarrow$ **Режим маршрутизации доменов** $\rightarrow$ настройте правила обхода или выберите конкретные приложения в пункте **Разделение трафика приложений**.
